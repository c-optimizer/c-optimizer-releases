## ⚠️ Sobre este repositório

Este repositório existe **apenas para hospedar os instaladores oficiais** do C-Optimizer.

O código-fonte do projeto é mantido em um repositório privado por motivos de segurança e propriedade intelectual. Nada aqui é código-fonte do aplicativo — somente os binários de instalação.

Se você baixou um `Source code (zip)` ou `Source code (tar.gz)` da página de releases, **isso não é o código do C-Optimizer** — é apenas um artefato automático do GitHub referente a este repositório de distribuição.

## 🚀 O que é o C-Optimizer?

Um aplicativo desktop completo para otimizar, limpar e manter o Windows focado em **performance em jogos** e **estabilidade do sistema**.

### ✨ Principais recursos

| Módulo | Descrição |
|---|---|
| 🎮 **Otimizações** | 48 tweaks curados (CPU, GPU, rede, privacidade, armazenamento) |
| ⚡ **Presets** | Modo Gaming, Privacidade, Minimalista e Rede com 1 clique |
| 🕹️ **Biblioteca de Jogos** | Detecta jogos em 10 launchers + adicionar manualmente |
| 🎯 **Perfil por Jogo** | Slider de intensidade, launch options e notas pessoais |
| 🌐 **Rede & DNS** | Teste de latência de 7 provedores + aplicação instantânea |
| 🧹 **Limpeza** | Arquivos temporários, caches, lixeira e logs |
| 📦 **Apps** | Instalar softwares (winget) e remover bloatware nativo |
| 🛡️ **Segurança** | Verificação de Defender, Firewall e UAC |
| 🔧 **Reparos** | DISM, SFC e CHKDSK com correção de loops |
| 💾 **Restauração** | Criação e aplicação de pontos de sistema |
| 🔄 **Game Mode** | Detecta jogos abertos e otimiza automaticamente |
| 🌍 **i18n** | Português (BR), Inglês (US) e Espanhol (ES) |

## 💻 Requisitos

- **Windows 10** (build 19041 ou superior) ou **Windows 11**
- **4 GB de RAM** (recomendado 8 GB+)
- **200 MB** de espaço em disco livre
- Privilégios de **Administrador** para aplicar tweaks de sistema

## 📥 Instalação

1. Acesse a página de [**última versão**](../../releases/latest)
2. Baixe o arquivo `C-Optimizer-Setup-x.x.x.exe`
3. Execute o instalador
4. **Se aparecer o aviso do Windows SmartScreen** (isso é esperado enquanto o instalador não é assinado digitalmente):
   - Clique em **"Mais informações"**
   - Clique em **"Executar assim mesmo"**
5. Siga o assistente de instalação
6. Pronto — o C-Optimizer estará disponível no Menu Iniciar e no Desktop

### 🔑 Ativação

Na primeira execução, você será solicitado a inserir uma **chave de licença**. Após ativada, o aplicativo funciona totalmente **offline** e a chave fica vinculada a este PC.
